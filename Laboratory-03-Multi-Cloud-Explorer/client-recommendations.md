<b>Checkpoint 4 – Cloud Platform Recommendation Challenge</b>

Client A – Startup Company
  A startup company wants to launch a new mobile application. Their budget is limited, but they expect rapid growth within the next few years.
  
> <b>Recommended Cloud Platform: Amazon Web Services(AWS)</b>

> <b>Why Amazon Web Services(AWS)?</b>

> AWS is the ideal choice for a budget limited start-up company with a projected high growth rate. AWS provides a generous free tier system which lets start-ups begin small and begin paying only for the resources that they utilize. AWS also represents the widest set of startup assistance programs including AWS Activate, which offers credits and technical support for young companies; Amazon EC2/AWS Lambda to deploy the backend application logic; Amazon DynamoDB/Amazon RDS for a flexible and scalable relational database; and  Amazon S3: to store and share files.

> <b>Client could use: </b>

> AWS App Runner / AWS Lambda - enabling serverless, cost-efficient scaling for unpredictable traffic.

> Amazon DynamoDB / Amazon RDS - for a flexible, scale data to store user and app data

> Amazon S3 - to store and serving app assets, images, and media files at low cost.

Client B – University
  A university already uses: ● Windows Server ● Microsoft 365 ● Active Directory. The university wants to migrate some services to the cloud.

  > <b>Recommended Cloud Platform: Microsoft Azure</b>

  > <b>Why Microsoft Azure?</b>

  > Upon reviewing the situation of the University, the university’s pre-existing usage of the Microsoft ecosystem (Windows Server, Microsoft 365, and Active Directory), it makes sense for them to switch to Azure which is well-integrated with these systems. The university’s transition to Azure will allow them to move their local Active Directory to the cloud through the Azure Active Directory, resulting in less disturbance in their operations and the need for retraining. Plus, using Azure benefits the university with massive hybrid cloud advantages when transferring their services little by little instead of moving everything at once. Microsoft also provides substantial discounts and grants in the education sector, which makes the change easier for the university in financial terms.

> <b>Client could use: </b>

> Azure Active Directory (Azure AD) - to utilize client could use 
> Azure Virtual Machines - to shift over by migrating existing  Windows Server workloads
> Exchange Online - to safely store data


Client C – AI Research Company
 > A research company develops Artificial Intelligence and Machine Learning applications that require high-performance computing.

 > <b>Recommended Cloud Platform: Google Cloud Platform (GCP)</b>

 > <b>Why Google Cloud Platform (GCP)?</b>

  > GCP is more ideal for a research organization concentrating in AI/ML since it is Google that holds the credit of being the frontrunner in machine learning infrastructure and provides technologies related to AI/ML that are considered to be one of the most sophisticated ones, including its specifically designed chips for model training. The TPU of Google guarantees the top-notch results in terms of the performance of deep learning processes, with both speed and quality in the world of AI. However, GCP doesn’t just offer an infrastructure for machine learning models, it also has competitive pricing for the application of high performance computing (HPC) and big data that fits the budgets of researchers.


 > <b>Client could use: </b>

 > Vertex AI - serves as a singular space for the development of machine learning models

 > Google Cloud TPUs / Compute Engine (GPU instances) - responsible for fast and effective development of big AI/ML models.

 > Cloud Storage - for storing large amounts of training data and model artifacts.


Client D – Global E-Commerce Company
> A multinational online shopping company serves customers around the world and requires highly available infrastructure with automatic scaling.

> <b>Recommended Cloud Platform: Amazon Web Services (AWS)</b>

> <b>Why Amazon Web Services (AWS)?</b>

 > Amazon Web Services (AWS) is the top platform for a multinational e-commerce company because of its extensive global infrastructure footprint, which allows for low latency for all manages to operate in the market. AWS has developed tools for automatic scaling and fault tolerance which are essential for dealing with peak sales periods. AWS has a well-established content delivery network and load balancing service, so its operations run smoothly everywhere. Choosing AWS also means having access to a multitude of guidelines and community support on how to use AWS for e-commerce.

> <b>Client could use: </b>

> Amazon EC2 Auto Scaling - for the automated increase or decrease of computing capability according to the real-time traffic demand.

> Elastic Load Balancing (ELB) - for traffic distribution over many servers to ensure high reliability and availability.

> Amazon RDS (Multi-AZ) / Amazon Aurora - for a highly available and scalable database which can fulfill global transaction volumes.
