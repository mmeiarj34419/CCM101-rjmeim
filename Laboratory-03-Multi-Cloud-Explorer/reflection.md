<b>Checkpoint 8 – Mission Reflection</b>

 After exploring the different kinds of platforms, out of three major platforms, Amazon Web Services (AWS) impressed me the most, AWS was built an ecosystem where services interconnect smoothly, letting a solution scale from a simple static website to a full enterprise architecture without switching providers. While searching the overview of the three platforms (Amazon Web Services(AWS), Microsoft Azure, and Google Cloud Platform (GCP)), it shows that those three platforms have the same core compute, storage, and networking primitives (virtual machines, object storage, VPCs), pay-as-you-go pricing, global data center footprints, managed database options, and increasingly overlapping AI/ML toolkits.  

 When it comes to business requirements, choosing a platform isn't really about which one is "best" in the service - it's about how it fits for the requirements needed. For instance, for native integration, we have the Azure for any company or universities already invested to Microsoft tools. A startup prioritizing cutting-edge data and AI services might lean toward Google Cloud Platform (GCP). Last, for Amazon Web Services(AWS) that tackles for wanting the widest range of proven services and hiring pool. The cost structure, compliance needs, existing technical debt, and team expertise all shape the decision as much as raw features do.

 In terms of acting as Cloud Solutions Consultant, it taught me think beyond  technical specs and start with the client's actual problem, the budget, scale, timeline, existing infrastructure — before recommending a platform. It elevated cloud computing from a purely technical skill into a consultative, to be business-aware one. For the last question, after doing the mission it strengthened my GitHub Cloud Computing Portfolio, where now I know to concrete, document the comparisons and hands-on the project artifacts that demonstrate not just theoretical knowledge, but applied reasoning of the evidence I can now point to when discussing my cloud expertise with future employers or clients.
