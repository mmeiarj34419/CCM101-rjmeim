● Brief Overview - Cloud Platform developed by Microsoft which integrates other Microsoft apps like Office 365, Outlook and many more.

● Global Infrastructure - Microsoft Azure has the largest number of regions Over 70 geographic regions worldwide.

● Cloud Management Console - You can access the console for Microsoft Azure in the Amazon Portal, includes user navigation and AI assistance.

● Four (4) Core Services
1. Virtual Machines
2. Blob Storage
3. Azure Functions
4. Azure SQL
   
● Three (3) Advantages
1. Microsoft Software apps integration.      
2. High Company Reliability 
3. AI Integration on the model.

● Typical Enterprise Use Cases
Microsoft Azure is often use to build and regulate an enterprise applications by migrating Windows and SQL Workloads.
