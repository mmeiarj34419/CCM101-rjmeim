> If this Linux server were migrated to the cloud, which AWS, Azure, and GCP services could host it?

If the Linux server was migrated to the cloud it would be possible to host it by using the following cloud services: using Amazon EC2 on AWS, using Azure Virtual Machines on Microsoft Azure and using Google Compute Engine on GCP. These are cloud services of each companies that can host virtual machines to accomodate linuxOS vm's in terms of software specifications.
